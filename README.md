## 安装方式

在 Operit 应用设置面板中，通过远程 MCP Server 配置指向对应 release 的下载链接即可。

以 DeepSeek 助手为例：

```
https://github.com/lwy521/OperitForge/releases/download/script-deepseek-v1.0.0/deepseek-v1.0.0.js
```
